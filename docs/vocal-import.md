# Vocal archive import runbook

This runbook imports the fixed Tai Song archive without making automated requests to Vocal. The only network actions are performed manually by the logged-in creator in a browser. Everything after capture is local, deterministic, and fail-closed.

The authoritative source for each article is the latest creator-dashboard/editor page saved as HTML. Reader mode, clipboard copies, and PDFs are not accepted as import inputs. A PDF may be saved only as a visual reference.

## Local paths

For each slug in [`provenance/vocal/inventory.json`](../provenance/vocal/inventory.json), create this ignored input bundle:

```text
.vocal-import/
└── raw/
    └── <slug>/
        ├── page.html
        └── hero-original.png
```

The importer writes only these reviewable outputs:

```text
provenance/vocal/posts/<slug>.json
provenance/vocal/manifest.json
src/content/posts/<slug>/index.md
src/content/posts/<slug>/hero-original.png
```

The sanitized JSON file is exactly `props.pageProps.post`; it excludes sibling account, client, and application configuration from `__NEXT_DATA__`.

## Capture one article

1. Sign in to the creator account and open the article from the creator dashboard. Confirm in the editor that it is the latest published version.
2. Save the complete page HTML to `.vocal-import/raw/<slug>/page.html`. Do not edit, prettify, or normalize the saved file.
3. Record the capture time as a canonical UTC timestamp such as `2026-07-21T19:23:45.000Z`.
4. Extract and inspect the original hero URL locally:

   ```powershell
   pnpm vocal:inventory -- --slug <slug>
   ```

5. Manually open the printed `post.heroImage.id` URL in the logged-in browser. Save the response bytes directly as `.vocal-import/raw/<slug>/hero-original.png`. Do not use a screenshot, image editor, optimizer, or format converter.
6. Preview the import without writing:

   ```powershell
   pnpm vocal:import -- --slug <slug> --captured-at <UTC-ISO-TIMESTAMP>
   ```

7. Review the planned paths, then write the outputs:

   ```powershell
   pnpm vocal:import -- --slug <slug> --captured-at <UTC-ISO-TIMESTAMP> --write
   ```

8. Re-extract the ignored raw inputs and compare every generated byte and field:

   ```powershell
   pnpm vocal:verify -- --slug <slug> --with-raw
   ```

9. Build the site and run the output checks:

   ```powershell
   pnpm check
   pnpm build
   pnpm verify:site
   ```

10. Compare the built article side-by-side with the saved Vocal page and optional reference PDF. Record the human result in [`provenance/vocal/review-checklist.md`](../provenance/vocal/review-checklist.md).

Never commit `.vocal-import/`. Before staging an article, inspect `git status` and confirm that only the sanitized snapshot, manifest, generated post, and exact PNG are new or changed.

## Batch discovery and final verification

After all 11 HTML files have been saved, print the 11 original hero URLs without making network requests:

```powershell
pnpm vocal:inventory -- --all
```

After all 11 articles have been written, require the fixed inventory, unique IDs and URLs, exact source-counted total of 15,593 words, byte hashes, PNG metadata, and regenerated output to reconcile:

```powershell
pnpm vocal:verify -- --with-raw --require-complete
```

The verifier intentionally fails if the manifest is absent, an article is missing, an unmanaged destination would be overwritten, a managed output changed outside the importer, an ID or slug is duplicated, or an integrity comparison differs.

## Reviewed source updates

Run a normal dry-run first. If an already imported Vocal source has intentionally changed, inspect that change and then use `--write --update` with the new explicit capture time. The updater refuses to replace a locally modified managed output whose current hash no longer matches the manifest.

## Fail-closed stop conditions

Stop and review instead of editing around an error when any of these occurs:

- `__NEXT_DATA__` is absent, duplicated, malformed, or does not contain `props.pageProps.post`.
- The source slug, exact title, community, author, source URL, or fixed inventory entry disagrees.
- The Slate body contains an unknown node, unknown mark, embed, body image, or media array.
- A source ID or URL is duplicated.
- The hero is not an original PNG or has unexpected dimensions.
- A destination exists without a matching manifest entry, or a managed file no longer matches its recorded hash.
- Any paragraph, leaf, mark, metadata field, timestamp, tag, caption, alt value, or source URL comparison differs.

Do not claim the archive is complete until the strict verifier passes and all 11 human-review rows are signed off.
