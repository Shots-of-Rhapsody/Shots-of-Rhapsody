# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy problem.
Use GitHub's **Report a vulnerability** form in the Security tab of the
[Shots of Rhapsody repository](https://github.com/Shots-of-Rhapsody/Shots-of-Rhapsody/security/advisories/new).

Include the affected file, route, or commit; a minimal reproduction; the
potential impact; and any suggested remediation. Do not include live
credentials, private Proton document links, raw author exports, or other
sensitive personal information in screenshots or logs.

The maintainer will acknowledge a complete report as soon as practical and
coordinate remediation before public disclosure. There is no bug-bounty
program or guaranteed response-time commitment.

## Supported version

Security fixes target the currently deployed release on `main`. Historical
commits and unpublished branches are not separately supported.
